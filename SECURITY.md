# Security Policy

## Reporting a vulnerability

Please **do not** open a public issue. Use GitHub's private vulnerability
reporting for this repository (**Security → Report a vulnerability**), or contact
the maintainer directly through their GitHub profile.

Include what you found, where in the tree, and how to reproduce it.

## Scope

In scope: this repository's install scripts, module configurations, and CI
workflows.

Out of scope: vulnerabilities in upstream projects referenced here — please report
those upstream — and anything that requires an already-compromised local account.
